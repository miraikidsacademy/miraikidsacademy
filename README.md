# 未来キッズアカデミー ホームページ引き継ぎメモ

このフォルダは，未来キッズアカデミーのリニューアル版ホームページです．
HTMLとCSSだけで作っているため，WordPressなどの管理画面はありません．
更新するときは，該当するHTMLファイルをテキストエディタで開いて編集します．

## まず触るファイル

| 更新したい内容 | 編集するファイル | 主に見る場所 |
|---|---|---|
| 毎月の活動予定を変える | `activities.html` | `更新箇所：毎月の活動予定` |
| 活動の記録に写真と文章を追加する | `records.html` | `更新箇所：活動の記録，写真，文章` |
| 新聞・Web記事などのメディア掲載を追加する | `news.html` | `更新箇所：メディア掲載情報` |
| 問い合わせ先を変える | 各HTMLの下の方 | `site-footer` |
| 色や見た目を変える | `assets/css/style.css` | CSS全体 |

## 1. 活動予定を更新する方法

編集するファイルは `activities.html` です．
ファイル内で次の目印を探してください．

```html
更新箇所：毎月の活動予定
```

変更する場所は主に2つです．

### 月を変更する

```html
<h2>9月の予定</h2>
```

例えば10月にする場合は，次のように変更します．

```html
<h2>10月の予定</h2>
```

### 日程を変更する

表の1行は次の形です．

```html
<tr><td>飛高会館</td><td>9/13(土)，9/14(日)</td><td>13:00〜16:00</td></tr>
```

意味は次の通りです．

```html
<tr>
  <td>会場名</td>
  <td>日程</td>
  <td>時間</td>
</tr>
```

予定を増やす場合は，1行分の `<tr>...</tr>` をコピーして追加してください．
予定を削除する場合は，対象の `<tr>...</tr>` を丸ごと削除してください．

## 2. 活動の記録を追加する方法

編集するファイルは `records.html` です．
ファイル内で次の目印を探してください．

```html
更新箇所：活動の記録，写真，文章
```

活動記録1件は次の形です．

```html
<article class="card record-card">
  <img src="画像ファイル名.jpg" alt="活動名の写真">
  <div class="body">
    <h3>活動名（年月日）</h3>
    <p>活動の説明文をここに書く．</p>
  </div>
</article>
```

### 例

```html
<article class="card record-card">
  <img src="2026-07-activity.jpg" alt="飛高会館での学習支援の写真">
  <div class="body">
    <h3>飛高会館での学習支援（2026/7/11, 7/12）</h3>
    <p>飛高会館にて学習支援を行いました．参加した子どもたちは，夏休みの課題や苦手分野の復習に取り組みました．</p>
  </div>
</article>
```

新しい活動を目立たせたい場合は，既存の活動記録より上に追加してください．

### 写真を追加するときの注意

- 写真ファイルは，HTMLファイルと同じ階層に置きます．
- ファイル名は半角英数字にすると安全です．
- 例：`2026-07-activity.jpg`
- HTML内の `src="画像ファイル名.jpg"` と実際の画像ファイル名を完全に一致させてください．
- 大きすぎる画像は表示が重くなるため，できれば横幅1200px程度までに縮小してください．

## 3. メディア掲載情報を追加する方法

編集するファイルは `news.html` です．
ファイル内で次の目印を探してください．

```html
更新箇所：メディア掲載情報
```

メディア掲載1件は次の形です．

```html
<article class="card">
  <h3>媒体名掲載</h3>
  <p>2026年○月○日に紹介されました．</p>
  <a href="記事URL" target="_blank" rel="noopener">記事を見る</a>
</article>
```

### 例

```html
<article class="card">
  <h3>中日新聞掲載</h3>
  <p>2026年7月15日に紹介されました．</p>
  <a href="https://example.com/article" target="_blank" rel="noopener">記事を見る</a>
</article>
```

新しい記事を目立たせたい場合は，既存のメディア掲載より上に追加してください．

## 4. よくあるミス

### 写真が表示されない

原因はほとんどの場合，画像ファイル名の不一致です．
例えばHTMLに次のように書いてある場合，

```html
<img src="activity.jpg" alt="活動写真">
```

同じフォルダ内に `activity.jpg` という名前の画像が必要です．
`Activity.jpg` や `activity.JPG` とは別物として扱われる場合があります．

### レイアウトが崩れた

`<article>`，`<div>`，`</article>`，`</div>` の消し忘れ・増やし忘れが原因になりやすいです．
コピーするときは，開始タグと終了タグをセットでコピーしてください．

### リンクが開かない

`href="..."` の中にURLを入れてください．
URLの前後の `"` を消さないようにしてください．

## 6. 更新後の確認手順

1. 編集したHTMLファイルを保存する．
2. ブラウザでHTMLファイルを開く．
3. パソコン表示とスマホ幅の表示を確認する．
4. 写真が表示されるか確認する．
5. リンクをクリックして正しいページが開くか確認する．
6. 問題なければサーバーへアップロードする．

## 7. 触らなくてよいファイル

`google32ebe3cd0aa9c821.html` はGoogle Search Console用の確認ファイルです．
意味が分からない場合は削除・変更しないでください．

`assets/css/style.css` は見た目を管理するファイルです．
色や余白を大きく変えたいとき以外は触らなくて大丈夫です．
