# 未来キッズアカデミー リニューアル版

## はじめに
このフォルダは、未来キッズアカデミーのホームページ一式です。
公開するページの中には、引き継ぎ用の「更新箇所」などの説明文は入れていません。
毎月の更新方法は、このREADMEまたは `引き継ぎガイド.html` を見てください。

## よく更新するファイル
| やりたいこと | 編集するファイル | 編集する場所 |
|---|---|---|
| 活動予定の日にちを変える | `activities.html` | 「9月の予定」などの予定表 |
| 活動の記録に写真と文章を追加する | `records.html` | 活動記録一覧の `<article class="card record-card">` |
| メディア掲載情報を追加する | `news.html` | メディア掲載一覧の `<article class="card">` |

## 1. 活動予定を更新する方法
`activities.html` を開き、予定表のこの部分を書き換えます。

```html
<tr><td>飛高会館</td><td>9/13(土)、9/14(日)</td><td>13:00〜16:00</td></tr>
```

例えば10月の予定にする場合は、見出しと日付を変更します。

```html
<h2>10月の予定</h2>
<tr><td>飛高会館</td><td>10/11(土)、10/12(日)</td><td>13:00〜16:00</td></tr>
```

予定を増やす場合は、1行分の `<tr>...</tr>` をコピーして追加してください。

## 2. 活動の記録を追加する方法
`records.html` を開き、活動記録一覧に次の形で追加します。
新しい活動を目立たせたい場合は、既存の活動記録より上に追加してください。

```html
<article class="card record-card">
  <img src="画像ファイル名.jpg" alt="活動名の写真">
  <div class="body">
    <h3>活動名（年月日）</h3>
    <p>活動の説明文をここに書きます。</p>
  </div>
</article>
```

写真ファイルはHTMLと同じ階層に置き、`src="画像ファイル名.jpg"` と完全に同じ名前にしてください。
ファイル名は、半角英数字がおすすめです。

## 3. メディア掲載情報を追加する方法
`news.html` を開き、メディア掲載一覧に次の形で追加します。

```html
<article class="card">
  <h3>媒体名掲載</h3>
  <p>2026年○月○日に紹介されました。</p>
  <a href="記事URL" target="_blank" rel="noopener">記事を見る</a>
</article>
```

## 4. 画像を表示するときの注意
画像が表示されない場合は、次を確認してください。

- 画像ファイルがHTMLと同じ階層にあるか
- ファイル名の大文字・小文字が一致しているか
- 拡張子が一致しているか
  - 例：`.jpg` と `.JPG` は別の名前として扱われることがあります

## 5. サイト全体の色やデザインを変える方法
色や余白などの見た目は、`assets/css/style.css` にまとめています。
HTMLではなく、基本的にはこのCSSファイルを編集します。
