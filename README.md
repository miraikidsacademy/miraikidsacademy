# 未来キッズアカデミー リニューアル案

## 変更点
- 各HTMLに重複していたCSSを `assets/css/style.css` に統合
- スマホ表示を前提にしたレスポンシブデザインへ変更
- トップページに活動内容・対象・支援導線を追加
- 活動予定を `<br>` と空白調整ではなく表で整理
- フッターの問い合わせ先を全ページで統一
- Google Search Console用の確認ファイルを保持

## 使い方
1. このフォルダ内のHTMLをブラウザで開く
2. 元サイトで使っていた画像ファイルを同じ階層にコピーする
   - 例：IMG_0081.png, IMG_4742.JPG, 119109.jpg など
3. 問題なければサーバーへアップロードする

## 注意
このZIPにはHTML/CSS/JSのみを含めています．画像ファイルは今回アップロードされていないため，同梱していません．
